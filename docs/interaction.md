# Interaction Guide

React Riyils is optimized for mobile-first interactions but provides full desktop support.

## Gestures (Viewer)

| Gesture | Action |
| :--- | :--- |
| **Long Press (Right Side)** | Increases playback speed to **2x**. Release to resume normal speed. |
| **Double Tap (Left/Right)** | Seek backward/forward by 10 seconds. |
| **Single Tap (Center)** | Toggle play/pause. |
| **Single Tap (Caption)** | Expand/collapse the caption sheet. |
| **Swipe Vertical** | Navigate between videos. |

## Keyboard Shortcuts

The following shortcuts are available when the `RiyilsViewer` is active:

- `Escape`: Close the viewer.
- `Space` or `K`: Toggle play/pause.
- `M`: Toggle mute.
- `Up/Down Arrows`: Navigate between videos (provided by Swiper).

## Haptic Feedback

On supported mobile devices (Android), the library triggers subtle haptic vibrations during seeks and UI interactions for a more tactile experience.
